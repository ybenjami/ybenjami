# Yaron Benjamin

**Software Architect & Founder | Applied AI, Distributed Systems and Enterprise Platforms**

I design and build platforms, and write about the architectural decisions behind them.

Over twenty years in software engineering, from engineering systems for the Department of Defense to directing a 60+ person technology organization and founding [Aionic Digital](https://aionicdigital.com/), where I remain hands-on in architecture and engineering.

My current focus is building AI-enabled systems that integrate with real enterprise platforms — with particular attention to reliability, security, evaluation and execution boundaries.

[Website](https://yaronbenjamin.com/) · [LinkedIn](https://www.linkedin.com/in/ybenjami) · [Aionic Digital](https://aionicdigital.com/)

## Engineering Focus

- **Applied AI & Agent Architecture:** agent orchestration, tool calling, context engineering, guardrails and human-in-the-loop workflows.
- **Retrieval Engineering:** retrieval-augmented generation (RAG), embeddings, vector search and retrieval quality.
- **Enterprise AI Integration:** Model Context Protocol (MCP), domain services, API abstraction and secure tool execution.
- **AI Reliability:** behavioral evaluations, deterministic execution boundaries and failure handling.
- **Distributed Systems:** event-driven architecture, cloud-native services, composable platforms and enterprise integrations.
